# CMPS 3350 Mini Project - Calculator

A simple calculator web app built with React and Python.

## Core Requirements
- Addition, subtraction, multiplication, and division
- Calculator UI/display
- Decimal input
- PEMDAS/operator precedence
- Parentheses
- Clear/reset
- Calculation history
- Results limited to 4 decimal places
- Error handling/input validation

## Stretch Goals
- Exponents
- Square root
- Modulo
- Factorial
- π and e
- Fractions
- Trigonometric functions
- Logarithms
- Scientific notation
- Themes
- Sound/visual effects
- Graphing
- Matrices/tables
